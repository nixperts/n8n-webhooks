# About

[N8n](https://n8n.io) allows users to create intricate flows and make
powerful connections between apps and automizations. Recently, I
stumbled upon it and when trying to use it for my own purposes, I found
that a plugin for [PayloadCMS](https://payloadcms.com/) would be very
useful.

# WARNING: Early work in progress

-   Don\'t expect this plugin to cover everything. It is still very
    early. High-quality issues and PRs are appreciated.
